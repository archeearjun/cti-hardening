# Separate authoring drafts on published items

The actual TRDE120 v1.8.6 manifest retains 43 of 44 publisher API originals,
including all five back-matter resources added in v1.8.6. Their actual hashes
and chapter-404 / part-404 / back-matter-200 chains validate. Publisher images
remain uncaptured: one exposed service challenge stopped subsequent service
requests to that origin. Deferred records are not fabricated HTTP responses.
The supplied PDF corroborates all 96 native item titles, order and publication
flags. It does not establish question bodies, external media or completeness.

The native assessment gap is separate. Four published atoms carry attached
`staffGradedDraft` models with 40 literal question-group references. The
draft-only current-source binder correctly rejects their published state, but
that previously prevented acquiring those separately observed drafts. The
existing native group and exact-version definition endpoints can read them
without guessing a published-body endpoint or opening an editor.

## v1.8.7 boundary

The same bookmark now retains `directAuthoringDraftSnapshot` as a separate
observation. A new pure binder requires the exact course, item, atom, relation,
material content ID and published assignment pointer. The attached model must
be a staff-graded draft on a published atom. Neither the existing draft binder
nor its native completion guards are relaxed.

Only literal group IDs are followed, under a separate 100-part limit. Unknown
and duplicate parts remain raw and explicitly unsupported. Each mutable group
is read before and after its exact versioned definition. A definition shared
by groups has one in-flight read for its exact ID; its receipt must have an
owning group observation as a timing witness. All group mappings, receipts,
hashes and distinct stability results remain retained. A final atom read checks
the full sanitized atom, both draft and published models, native modification
value and stored version. The ordinary final material check still applies.

Source and group failures preserve partial observations. A later attempt keeps
every earlier snapshot in a flat `directAuthoringDraftSnapshotHistory` array;
it does not replace older definitions with an empty failed read. The existing
manifest and run bounds still apply. The independent owner view has a separate
bounded review budget and reports deferred projection explicitly. It never
deletes original capture records to fit that view.

These snapshots always declare published-content, whole-item and complete
coverage verification false. They never populate the primary question list,
answer counts or `structuredAssessment`. Progress reports additional retained
draft definitions separately. Completed v1.8.6 checkpoints can acquire this
previously skipped evidence while preserving existing primary assessment
observations and their dates.

## Retained typed fields

Existing validated authoring originals gain an on-demand view for exact-answer,
reflection and instruction models. Literal answer strings preserve spelling
and whitespace. Explicit native correctness flags, absent keys and answer-key
applicability remain distinct. Feedback fields distinguish present text,
explicit empty CML, absent fields and unsupported formats. Instructions remain
instructions, not invented questions. These display fields do not alter the
persisted supplemental block schema, original JSON, hashes or native verdicts.

Current published assignment/reading/coach body routes remain unproved by the
supplied evidence. A published reading's versioned `@2` reference cannot be
replaced with its attached `@1` draft or treated as binary `assets.v1` metadata.
An Archive folder name does not establish learner hiding, and a literal
"no source content" placeholder is retained authored text rather than a verified
empty body. Grading settings already exposed from bound drafts remain separate
from generic material types and older published snapshots.

Synthetic tests establish these acquisition, retention and view boundaries.
They do not certify a future live course, access to blocked publisher images,
learner matching behavior or whole-course completeness.
