## Confirmed follow-up changes

- Coursera bookmark v1.7.6 retains supported native `.dwg` originals instead of
  rejecting their response MIME. It requires the native drawing filename,
  supported MIME, recognized AutoCAD header, exact positive identity framing,
  stable native metadata, complete bounded bytes and SHA proof. The original
  Content-Type declaration is retained separately from its normalized MIME.
  No drawing text, screenshot or replacement image is generated.
- Brightspace bookmark v1.2.1 admits only explicitly identified, same-origin
  `.dwg` URLs under the current course's enforced-content container. Collector
  and importer independently check scope, framing, signature and original
  bytes. Other-course, external, encoded-separator and guessed tool URLs remain
  unresolved. Existing byte, time and request limits are unchanged.
- A URL-present external attachment has an unfetched external-source reason,
  distinct from a native image without a pointer. The external FOIP PDF in
  reading NGwET is not automatically fetched or labelled complete.
- The owner view separately exposes retained native authoring blocks that
  cannot enter the normalized question projection: typed-answer and reflection
  definitions, an instruction-only text block, and unsupported original CML.
  Exact native identity, part/group/definition ownership and saved proof are
  checked independently. This supplemental view changes neither question totals
  nor completeness, answer keys, scores or saved raw observations.
